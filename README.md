<h2>Medical Records Management System<h2>
A full-stack web application built with Django designed to streamline personal health management. This platform bridges the gap between patients and healthcare providers, offering a centralized hub for medical history, especially for users managing chronic conditions.

<h3>Project Overview<h3>
Managing long-term health issues often involves a mountain of paperwork and frequent communication hurdles. This app provides:

<ul>
  <li> Centralized Records: A secure place to store and view medical history, test results, and prescriptions.</li>
  <li> Monitoring: Tools for patients to track symptoms or vitals over time.</li>
  <li>Efficiency: Streamlined communication channels to make doctor-patient interactions more data-driven and effective.</li>
</ul>

<h3>Tech Stack<h3>
<ul>
  <li>Backend: Python / Django (MVT Architecture)</li>
  <li>Frontend: JavaScript, HTML5, CSS3 (Bootstrap)</li>
  <li>Database: SQL</li>
  <li>Authentication: Django Auth system for secure patient/doctor logins.</li>
</ul>
